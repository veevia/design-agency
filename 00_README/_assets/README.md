# README assets

**TL;DR:** The animated overview at the top of the repository README and its still image live here; both describe Design Agency OS 2.0.0.

| File | What it is |
|---|---|
| `design-agency-os.gif` | 1920 × 1080, 25 fps, a 21.6-second loop: the five task steps, what each step uses, the project hub's four phases and the six contracts, with one step in focus at a time |
| `design-agency-os.png` | The first and last frame: the complete overview, for print, previews and reduced motion |

- The style matches the FDE Design Toolkit and VPG overviews: Geist and Geist Mono type (SIL Open Font License 1.1), neutral surfaces, and sub colors only on small entities (violet for agents, blue for tools and evidence gates). The GIF palette holds every color token exactly.
- The facts come from [AGENTS.md](../../AGENTS.md), the [operating guide](../../00_Agentic-OS/README.md), [ARCHITECTURE](../ARCHITECTURE.md) and `agency.py status` at version 2.0.0. Redraw the animation when a count it shows changes: 87 skills, 21 review rows, 136 unit tests, 5 steps, 4 phases or 6 contracts.
- Images here carry no metadata; the privacy gate scans them before every release.
