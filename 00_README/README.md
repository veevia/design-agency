## Rules

- **Frameworks explain; templates structure; skills operationalize.** One source of truth per concept;
  [AUTHORITIES](../AUTHORITIES.md) says which file owns what.
- **New policy goes to its owner.** A naming, tag or hygiene rule changes [CONVENTIONS](CONVENTIONS.md); a new
  discipline lands in `_frameworks/`; a durable choice goes through [W5](../02_Workflows/workflows/W5-decide.md).
- **New templates** follow the pattern in the [template catalog](_templates/README.md) and get one catalog row — no
  second list elsewhere.
- **Gaps and ideas** go to the [OS backlog](../00_Agentic-OS/OPTIMIZATION-BACKLOG.md), not into these guides.
