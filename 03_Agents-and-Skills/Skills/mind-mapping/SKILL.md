# Mind Mapping

**TL;DR:** A radial free-association exercise where the sprint challenge sits at the centre and ideas, associations, and sub-concepts branch outward. Not a brainstorm — no evaluation, no grouping, no one idea "winning." The goal is to break fixation on the first solution frame and surface concepts that may not emerge in structured methods.

## When to use

- As a 10-minute warm-up before Crazy 8s
- When the team is anchored on one solution (the same idea keeps coming up)
- When the problem space is new and the team needs to diverge before converging

## Materials

- Paper and pen (individual), OR
- A shared digital whiteboard with sticky notes
- Timer: 8–10 min

## Steps

1. **Write the sprint challenge in the centre (1 min):** Use the target moment from the sprint map — e.g., "the Lead Coordinator checking a request."
2. **Free-associate outward (8 min, silent):** Branch outward in any direction:
   - What words come to mind?
   - What analogies? ("It's like a...)
   - What systems does this remind you of?
   - What are the opposite approaches?
   - What would make this worse? (Reverse it)
3. **Go 3 levels deep on at least 2 branches:** Don't stop at the first association. Push: "And then what? And then what?"
4. **Mark the most interesting branches (2 min):** Circle 2–3 nodes that feel unexpected or generative — not the obvious ones.
5. **Optional share (3 min):** Each person names one surprising branch they want to explore in sketching.

## Mind map structure

```
                    [word / idea]
                          │
        [word]──────[SPRINT CHALLENGE]──────[word]
                          │
                    [word / analogy]
                          │
                  [sub-concept] ── [detail]
                          │
                  [sub-concept] ── [counter-idea]
```

**Example for "the Lead Coordinator checking a request":**
```
                    "trust calibration"
                           │
"inbox triage" ──── "request checking" ──── "second opinion"
                           │
                     "urgency score"
                     ├── "doctor diagnosis: differential → likely → confirmed"
                     ├── "weather forecast: % probability"
                     └── "ER triage: red / amber / green"
```

## Productive mind map branches

Prompt yourself or the team with these frames if stuck:

| Frame | Example branch |
|---|---|
| Analogy | "This is like [known system]" |
| Reversal | "What if users couldn't check anything at all?" |
| Scale | "What if there were 1000 requests/day instead of 10?" |
| Extremes | "What if the user was a first-day intern? A CEO?" |
| Emotional | "What would make this feel effortless? Trustworthy? Dangerous?" |
| System | "What happens upstream? Downstream? In parallel?" |

## Agent facilitation guide

When building a mind map to seed a design:
1. Start with the sprint target moment as the centre node
2. Generate 3–4 first-level branches (user actions, system behaviours, analogous domains, emotional states)
3. Go 2–3 levels deep on the most generative branches
4. Extract the 3 most unexpected/interesting leaf nodes
5. Use those as explicit anchors for the first 3 panels in Crazy 8s

When reviewing a team's solution ideas for narrow thinking:
- Build a quick mind map of the proposed solution space
- Identify which quadrant is underpopulated
- Generate 2–3 ideas for that quadrant to expand the design options

## Output

Individual mind maps (not shared widely — they're raw material). Each person marks their 2–3 most generative branches and carries them into Crazy 8s.

## Watch-outs

- **Evaluating while mapping:** "That won't work" has no place here. Evaluation is Phase 4.
- **Staying shallow:** One level of associations is not a mind map — it's just brainstorming. Push to 3 levels minimum.
- **Convergence pressure:** If one person's node dominates the group discussion, the method has become a pitch. Keep this individual and silent.
- **Skipping it for "speed":** Teams that skip the warm-up often produce Crazy 8s that are all variations of the same idea. 10 minutes here saves 2 hours of monotonous sketching.
