# I Like, I Wish, What If

**TL;DR:** "I Like, I Wish, What If" (IL/IW/WI) is a structured feedback technique that separates positive observations, constructive wishes, and generative ideas into three distinct lanes. It prevents critique from becoming pure criticism, forces the team to notice what's working before proposing changes, and generates "What If" ideas that often become the seeds of the winning concept. Used alongside Speed Critique, it produces richer design conversations in less time.

## When to use

- As a complement to Speed Critique — after the structured observations, use IL/IW/WI for the "what could be better" layer
- When critique is devolving into debate or personal preference
- When the team needs to be more explicit about what to preserve in the winning concept
- In situations where the sketch creator is visibly defensive — IL/IW/WI's appreciative opening reduces defensiveness
- When the team has junior members who struggle to give structured feedback

## The three lenses

| Lens | Phrase | What it captures | Sprint use |
|---|---|---|---|
| **I Like** | "I like that..." | Specific positive element worth preserving | Identifies what must not be lost when iterating |
| **I Wish** | "I wish that..." | A specific improvement — framed as a desire, not a criticism | Surfaces refinements without triggering defensiveness |
| **What If** | "What if..." | A generative idea — a new possibility the sketch sparked | Generates the combinable elements for the Supervote |

## Rules

- **One sentence per lens, per person.** No paragraph explanations.
- **Start with I Like — always.** Not optional. Even the weakest sketch has one thing worth noting.
- **I Wish is not I Don't Like.** "I wish the urgency score were more prominent" vs. "I don't like how small the urgency score is." The wish is actionable; the criticism isn't.
- **What If is generative, not corrective.** "What if we moved the records list to a side panel?" opens a new direction. "What if we fixed the assignment form?" is a correction, not an idea.
- **No debate on What Ifs.** Post them as seeds for Phase 3 (if still in discovery) or as Straw Poll input.

## Steps

1. **Each person writes silently (2–3 min):** One I Like, one I Wish, one What If per sketch — on three different coloured stickies. No discussion.

2. **Go around the room (3–5 min):** Each person reads their three stickies aloud. Scribe posts them in three separate columns above the sketch.

3. **Cluster the What Ifs (2 min):** Are there themes? A recurring "What If" from multiple people is a strong candidate for the Straw Poll or for the Assumptions Board.

4. **Creator responds (30 sec):** One sentence — can clarify a misunderstanding. Cannot defend.

## Output format

```markdown
## I Like / I Wish / What If — Sketch: "Reasons-First Triage"

### I Like
- The urgency score is the first thing I see — it answers my question before I have to look for it
- The inline records list replaces the system-switching I do every morning — this is a direct pain solve
- The assign CTA is present but secondary — right priority
- The annotation explains the score — "based on 3 matching records" tells me the reasoning, not just the number

### I Wish
- I wish the urgency score had a colour cue as well as a number — for faster scanning at 38 requests a morning
- I wish there were a way to disagree with the suggested priority — right now there's no "I think this is wrong" action
- I wish the specialist were pre-filled based on request type — manual selection feels like it defeats the purpose

### What If
- What if each record had a reliability indicator — "confirmed booking" vs. "unconfirmed booking"?
- What if changing the suggested priority added your note to the model's training data?
- What if the urgency score showed a trend — "U-200 units usually score low; this week three scored urgent"?
```

## IL/IW/WI vs. Speed Critique

| | Speed Critique | I Like / I Wish / What If |
|---|---|---|
| **Focus** | What's interesting / what's an assumption | Positive / improvement / generative |
| **Tone** | Observational | Appreciative → constructive → generative |
| **Output** | Standout ideas + concerns (stickies) | Three-column structured feedback |
| **Creator role** | Speaks last, 30 seconds | Same |
| **Use together** | Run Speed Critique first; use IL/IW/WI for the "wish" and "generative" layers |

## Agent facilitation guide

When generating IL/IW/WI feedback on a solution sketch:
1. Read the sketch description and annotations carefully
2. Write one specific I Like — name the element, not a vague positive
3. Write one I Wish — frame as a desire ("I wish X were Y"), not a deficiency
4. Write one What If — a generative idea sparked by the sketch, not a correction
5. Repeat for each sketch
6. After all sketches: identify recurring What Ifs — these are the Straw Poll seeds

## Watch-outs

- **Skipping I Like:** The appreciative opening is not optional — it changes the emotional tone of the entire session. "I wish everything were different and what if we started over" is not useful feedback.
- **I Wish becoming I Don't Like:** Tone matters. "I wish the assign action were more prominent" opens the door; "the assign action is buried and wrong" closes it.
- **What If as a solution:** "What if we built a new collaboration layer?" is a significant scope addition, not a "what if." Keep What Ifs to variations within the concept, not entirely new directions.
- **Running IL/IW/WI instead of Speed Critique:** These methods complement each other. Speed Critique provides structured observation; IL/IW/WI provides structured reaction. Use both.
